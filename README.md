ABSTRACT:
The core idea is to create a platform for people to search for medicines availabe in the nearby medical stores. This may not seem to be useful in metopolitan cities
where platforms like NETMEDS provide direct delivery but this can be useful in cities where such sservices are not available. This also shows the quantity of medicines
in the medical stores. This shows the medical stores only in the radius entered in the beginning. This is just the user end website. We also need to create a store end
version and link these to a single database. These updates will be monitored and authorised through suitable methods. If this is brought under the government and made 
mandatory to all medical stores and all medicine suppliers to update on their sales, then this can be monitored very well and brings the whole drug industry under one
website and also be accessible to citizens.
